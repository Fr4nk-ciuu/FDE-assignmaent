## 1. 任务 1 · 开展角色访谈（访谈记录与角色地图）

### 1.1 最近一单：开学第一周实训室占用引发的选课冲突

按角色口述还原的完整过程：

1. **触发点**：实训室因设备维护被临时占用，排课表仍把该场地标为可用（林亦舟）。
2. **发现时点**：选课首日上午，学生在列表看到该课程并提交，提交后才提示先修课不满足或教室冲突（林亦舟）。
3. **节点顺序**：教学计划 → 排课 → 选课 → 冲突校验 → 调整 → 名单确认（顾明岚、唐映秋两人描述一致）。冲突校验实际发生在选课之后，而不是排课完成时。
4. **上报路径**：学生在班级群询问 → 辅导员手工登记 → 以群消息和便签转排课专员，全程没有业务单号（林亦舟）。
5. **交接规则对照**：要求「业务编号、当前版本、处理状态、未解决事项、接手人」五项齐全、对方确认接手才算完成（唐映秋）——本单五项全缺。
6. **核对**：排课专员回查场地预约与教师排班，确认场地确被占用（唐映秋）。主数据为培养方案、先修关系、教室容量、教师排班四类。
7. **决策**：改课方案由排课专员发起；超出「整理、校核、发起复核」范围的部分须教务确认（唐映秋）。本单实际走了口头确认，无审批单据。
8. **输出**：改课通知发群，学生重新选课，名单确认顺延（林亦舟、唐映秋）。
9. **返工点（4 处）**：学生重新选课；辅导员重复解释同一问题；排课专员二次核场地；名单重出。
10. **规模锚点**：该单是开学周日均约 120 个调整请求之一，学期约 420 门次课程（林亦舟、叶书）；学期冲突约 360 起、目标压到 80 起，调课期望由 3 天降到 1 天（顾明岚）——三项均为口述，无计时与日志支撑。

## 2. 任务 2 · 还原现状流程（现状流程图与异常路径）

> 图形版见 `现状流程图.html`（含泳道、异常路径卡、判断点与瓶颈责任表）。以下为文字版，便于粘贴与检索。

### 2.1 六节点主流程

| 节点 | 责任岗 | 输入 | 输出 | 留痕 | 卡点 |
|---|---|---|---|---|---|
| ① 教学计划 | 叶书＋教务 | 培养方案、先修关系 | 学期开课计划 | 培养方案版本（无版本台账） | 先修关系变更不同步到选课端 |
| ② 排课 | 唐映秋 | 教室容量、教师排班、场地预约状态 | 课表草案 | 课表文件（无版本号） | 场地占用变更不在输入内 |
| ③ 选课 | 学生自助＋林亦舟辅导 | 可选课程列表 | 选课记录 | 系统日志（有时间戳，可导出） | 列表生成时不做资格实时校验 |

### 2.2 异常路径（四条）

**A 场地占用未同步**
发现：学生提交被拒 → 路径：②输入失真 → ③看到可选 → ④校验不过 → ⑤人工改课 → ⑥名单顺延 → 处置：排课专员回查场地预约后改课，全程无单号 → 责任人：场地管理方（未列入访谈）＋唐映秋 → 后果：返工集中在开学周。

**B 口头说明不入单**
发现：交接时对方不知道前情 → 路径：②／⑤信息丢失 → 重复询问 → 重复处理 → 处置：靠人来电或群里再问一遍 → 责任人：林亦舟→唐映秋 → 后果：返工不可计量，M3 无法计算。

**C 规则两版本冲突**
发现：同一课程两次校验结论不同 → 路径：④判定不一致 → 流程停摆 → 两版并附上报 → 处置：交教学质量专员裁定，不自行合并、不选宽松条款 → 责任人：唐映秋→傅景 → 后果：单笔时间不可控且无留痕。

**D 接口中断**
发现：页面数据停更 → 路径：④改用上一份带时间戳只读快照并标「暂未更新」→ 重连按业务编号去重补齐 → 处置：现有人工流程继续，不反复触发同一待办 → 责任人：秦芮 → 后果：识别率统计须扣除停更样本。

### 2.3 理想流程 vs 现场做法

| # | 理想 | 现场 | 改造方向 |
|---|---|---|---|
| 1 | 校验在排课完成即执行 | 校验在选课之后 | 把校验前置为排课节点出口条件 |
| 2 | 场地状态由预约系统同步 | 课表静态，事后才发现 | 场地占用作为排课输入字段，超期标待刷新 |
| 3 | 说明随单交接 | 便签与群消息 | 交接五项设为必填，未填不得转交 |
| 4 | 退回原因必填、返工可统计 | 原因非必填 | 退回时强制选原因码 |
| 5 | 单一有效规则版本 | 两版并存靠人裁定 | 建规则版本台账，按生效日期锁定 |

### 2.4 只能由人完成的五处判断（范围边界）

1. 课程资格与公平分配的特殊申请确认（教务）。
2. 两版本规则取舍（教学质量专员）。
3. 错误建议的暂停—核对—继续（辅导员提出、排课专员确认）。
4. 是否转人工的触发判定（场地占用未同步／资料缺依据／两版本冲突／关键系统不可用）。
5. 名单最终确认与签核（以接手人确认为完成，专业签核不可代签）。

**含义**：这五处决定了「不自动选课、不改成绩」不是保守做法，而是流程结构决定的硬边界。

### 3.4 材料核对（逐份结论）

- **01 客户简报**：可作背景（开场、边界、样本），不可作证据｜缺陷 3 处：目标段落重复、角色诉求为空模板、无时间与版本。
